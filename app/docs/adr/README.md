# Architecture Decision Records

One file per significant decision, named `ADR-NNN-short-title.md`, containing
Context, Decision, Alternatives considered, Consequences and Status.

Rules:

- An accepted ADR is never rewritten. Supersede it with a new ADR that links back
  and set the old one's status to `Superseded by ADR-NNN`.
- Keep the decision list in [PROJECT.md](../../PROJECT.md) in sync.
- A decision that changes architecture, security, data or a public contract needs
  an ADR; a routine implementation choice does not.
