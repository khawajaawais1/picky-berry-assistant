# Data contract — what `data/` produces (owner: Awais)

Consumers should rely only on the columns below. Changes go through a PR that tags the consumer.

## zones (D10) → Hassan (API), Remon (scoring), Salman (offline snapshot)

| column | type | notes |
|---|---|---|
| id | uuid | **stable**: uuid5(namespace, h3) |
| h3 | h3index (text without h3-pg) | resolution 8 |
| h3_parent6 | h3index | for zoomed-out mode (zoom < 10) |
| name | text | nearest OSM place + rank, e.g. "Laajavuori 3"; fallback "Zone 5CF1B" |
| forest_type | text | mire · forest_spruce · forest_pine · forest_mixed · forest_broadleaf · forest_unknown |
| forest_fraction, mire_fraction | real 0–1 | share of the hexagon |
| habitat | jsonb | habitat class → fraction (input to zone_species) |
| fertility_class | smallint null | MS-NFI site class, when rasters were used |
| area_km2 | real | ≈ 0.57 |
| centroid | Point 4326 | |
| geom | Polygon 4326 | full hexagon, not clipped |
| source_version | text | e.g. `osm-finland-latest-free-20261022/h3r8/v1` |

## zone_species (D11) → Remon

`(zone_id, species) → suitability 0–1, rules_version`. A missing row means the species
cannot occur there (proposal: hide on the map – open question for Asmer).

## weather_daily view (D13) → Remon

`(zone_id, date) → tmean_c, precip_mm, gdd_since_apr1, ingested_at`.
`weather_age_days = current_date - max(date)` per zone (confidence drops one level if > 7).

## ndvi_zone_latest view (D14) → Remon

`zone_id → period_start, ndvi_mean, ndvi_anomaly`. No row → use anomaly 0.

## ingest_runs → Hassan (job runner, admin page), Sayeem (QA)

One row per loaded source per run: `source, started_at, finished_at, status (ok|failed), rows, error, details`.
A failed run keeps yesterday's data.

## zone_features (planned, sprint 2–3) → Remon (6.6)

zone × species × day: `gdd_since_apr1, precip_30d, frost_days_flowering, ndvi_latest, ndvi_anomaly,
doy, forest_type, reports_7d, last_year_score` — reports columns come from Hassan's tables.
Columns to be agreed with Remon before building.

## Basemap (D18) → Salman, Sabih

`finland.pmtiles` (Protomaps schema, maxzoom 14) **to be placed** in bucket `tiles/` — no bucket
or object exists yet — plus `style.json` generated by `data/scripts/make_style.mjs` pointing at it
via `pmtiles://`. The extract script is ready; it needs the `pmtiles` CLI installed, and no tile
file is committed or uploaded.

## Stub (until real zones land)

`data/test_zones.geojson`: 50 zones around Laajavuori, each feature already in the
`GET /api/v1/zones?species=bilberry` shape (`ZoneProps`) plus `scores` for all four species.
Each feature also carries `updated_at` (ISO 8601 with a zone or `Z`), the instant its scores were
computed. The app prints the oldest one in the set beside the map as its “last updated” line, and
prints no line when any zone it is showing has none — so a consumer that regenerates the file must
keep the field if the map is to keep stating its age.
